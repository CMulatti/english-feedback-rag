# Institutional criteria for applying the Cambridge A2 rubric

## Scale
- Each criterion is scored from 0 to 5.
- Half points are allowed. Use x.5 when the text fully meets band x
  and shows some, but not all, features of the band above, or when a
  rule in this file lowers the score by half a band.
- Band 5 does not require a perfect text. Isolated minor problems do not
  prevent band 5 if the text meets the band descriptor overall.

## Content
- All essential content points of the task must be answered and
  clearly developed for the reader.
- A content point can be answered implicitly, as long as the reader can
  clearly understand the writer's position.
- A text can omit one accessory content point and still reach band 5,
  as long as the essential points are fully developed.
- Omitting more than one accessory point, or any essential point,
  prevents band 5.
- Content points can be answered in any order.
- Length is assessed through Content: texts below the expected length
  usually cannot develop all content points.
- A text below 80% of the minimum expected length cannot reach band 5.
  A text at 80% or more that is well developed can reach band 5.
  Texts above the maximum expected length are not penalized.

## Language
- Vocabulary is assessed against the course, not only against general A2:
  using correct basic words instead of the taught vocabulary is not an error,
  but it shows less command of the course content.
- If no taught vocabulary appears, Language cannot exceed band 3.

## Interaction between criteria
- Each error is penalized only under the criterion it belongs to.
- Language errors affect Content only when they prevent a content point
  from being understood. In that case, Content justifies it as
  "point not communicated", not as an error.
- Punctuation that affects sentence boundaries is assessed under Organization.


## Format
- The expected format of each task (e.g. greeting and ending in a reply)
  is assessed under Organization.
- When the task requires a greeting, its absence lowers Organization
  by half a band.
- A missing or weak ending does not lower the score, but it should be
  mentioned in the feedback.
